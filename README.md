# PNLIO Framework

## Framework experimental para análisis de coherencia informacional y procesamiento neuro-lingüístico inverso

PNLIO (Programación Neuro-Lingüística Inversa Ontológica) es un proyecto de investigación y desarrollo orientado a explorar métodos computacionales para el análisis de coherencia informacional, inferencia ontológica y trazabilidad de interacciones humano-IA. El repositorio reúne documentación técnica, herramientas Python, notebooks, informes y evidencias de experimentación.

> El proyecto se presenta como un framework experimental y reproducible. Sus hipótesis, métricas y resultados deben evaluarse mediante revisión técnica, ejecución del código y replicación independiente.

## Estado del proyecto

La rama principal contiene materiales asociados a las versiones v6, v7 y v9, incluyendo el analizador de coherencia informacional, documentación de métricas ontológicas y papers de investigación. La versión indicada en la documentación histórica no implica validación científica externa de todas las hipótesis; cada documento debe interpretarse según su metodología y alcance.

## Componentes principales

El framework combina documentación conceptual, análisis de coherencia, medición de relaciones informacionales y materiales de investigación. El objetivo operativo es proporcionar una base local para experimentar con métricas, protocolos de análisis y modelos de inferencia aplicados a sistemas de IA.

## Inicio rápido

### Linux y macOS

```bash
git clone https://github.com/godear6959-creator/PNLIO-Framework.git
cd PNLIO-Framework/tools/pnlio-coherence-analyzer
pip install -r requirements.txt
python pnlio_coherence_analyzer.py
```

### Windows

```powershell
./tools/nik_autodescarga.ps1
```

El analizador genera un gráfico de coherencia informacional y un reporte asociado al análisis del Efecto Reflex, según la configuración disponible en el proyecto.

## Alcance y reproducibilidad

PNLIO es un experimento de investigación en progreso. Los resultados deben interpretarse junto con el código, los datos disponibles, las versiones de las herramientas y las limitaciones descritas en cada documento. Se recomienda reproducir los análisis en un entorno aislado, registrar las dependencias y separar claramente las observaciones empíricas de las hipótesis teóricas.
